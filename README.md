# S01E03 · what it shows

Review of the support desk's date reports in ticket #4471 for the MEGA.dev course. All tenant and report data here comes from the course's fictional support-desk export dated 2026-10-04.

The export has **427 rows, 412 unique reports**. The supplied cause logic, using tenant locale, form version and report channel, separates **379 parser reports** and **33 booking-v3 form-hint reports**. The five documented one-day/timing anomalies remain visible as unresolved evidence within the parser allocation. These counts describe the export, not a live queue.

The course accepted both ticket allocations, then published an [engineering update](docs/engineering-update.md): #4471 closed on 5 October. **Parser: fixed**, `fix(dates): parse dd/mm for eu locales`. **Hint: won't fix**, booking-v3 form retired. The issue closure reasons are completed and not planned respectively.

## Reproduce and preview

Use Node.js 22.12 or newer (Node 24 was used for this build).

```sh
npm ci --ignore-scripts --registry=https://registry.npmjs.org
npm run build
npm run preview -- --port 4173
```

Open <http://127.0.0.1:4173/kb/incidents/4471-review/>. The static HTML contains the actual rendered counts, chart and derived signature stamp before JavaScript runs. The client bundle hydrates the deduplication explorer for interaction. Serve `rendered/` as a directory to keep navigation and interactive controls working.

`npm run analyze` imports the course's original `causes.ts`, deduplicates report IDs, resolves tenants from their individual JSON files, and produces the allocation file. Numbers in the kb review are computed in components from the same export.
